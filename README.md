
# AI Support Ticket Classifier

A machine learning application that automatically classifies customer support tickets based on their text.

## Tech Stack
- Python
- pandas
- scikit-learn
- Streamlit

## Features
- Customer support ticket classification
- TF-IDF text vectorization
- Logistic Regression classification
- Model evaluation and performance metrics
- Interactive Streamlit interface (planned)

## Dataset
Support Ticket Router 12K Cleaned

Source:
https://huggingface.co/datasets/cngchis/Support-Ticket-Router-12K-Cleaned

Download train.jsonl, val.jsonl, and test.jsonl into the data/ directory.
